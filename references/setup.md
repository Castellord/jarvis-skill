# Настройка

Прежний мастер задавал шесть блоков вопросов до первого полезного действия.
Теперь наоборот: **сначала результат, потом вопросы, и только те, на которые
нельзя ответить за пользователя.**

## Первый запуск (ноль обязательных вопросов)

1. `mcp__emailmcp__email_accounts_list` — берём **все** аккаунты. Список пуст —
   единственная блокирующая ситуация: скажи, что нужно подключить почту через
   `mcp__emailmcp__email_connect_url`, и остановись.
2. `mcp__linear__list_teams` и `mcp__linear__list_projects`. Одна команда —
   берём её молча. Один проект — берём молча. Несколько — берём тот, где
   пользователь автор или ассайни большинства свежих задач. Linear недоступен —
   работаем в режиме «только сводки», задачи не заводим, говорим об этом строкой.
3. Создаём файл правил с выбранными дефолтами:
   ```bash
   python3 scripts/jarvis.py init --team <TEAM_ID> --project <PROJECT_ID>
   ```
4. **Сразу делаем то, за чем пришли** — разбор или отчёт.
5. И только после результата — одна строка:
   `Настроено на дефолтах: почта — все аккаунты, задачи — <Команда> / <Проект>. Скажи «настройки», если хочешь поменять.`

Если на шаге 2 выбор неочевиден (несколько команд, ни одна не выделяется) —
задай **один** вопрос с вариантами. Один, не серию.

## Явная настройка («настройки», пункт 4 меню)

Покажи текущее состояние одним блоком и спроси, что менять. Не веди по всем
пунктам подряд.

```
Аккаунты: все (3)
Задачи: Gugaevegor / GTD — Таск трекер
Спрашивать перед созданием задач: да
Сводка: 24 часа, до 8 пунктов, Europe/Moscow
Правил шума: 4, категорий роутинга: 2

Что поменять?
```

Значения не сбрасываются — текущее предлагается как дефолт для правки.
Изменения записывай сразу, по одному, подтверждая строкой.

## Категории роутинга

Отдельно **не спрашивай**. Категория заводится тогда, когда пользователь
впервые говорит «это в проект X» — см. `references/feedback.md`. Так набор
категорий отражает реальную почту, а не гипотезы на старте.

Исключение: пользователь сам просит настроить категории заранее. Тогда для
каждой спроси имя, ключевые слова/домены и team/project, и запиши через
`scripts/jarvis.py add-route`.

## Проверка после изменений

По просьбе «проверь настройки» прогони:

```bash
python3 scripts/jarvis.py selftest
python3 scripts/jarvis.py match --from "test@example.com" --subject "Тест"
```

Плюс один реальный вызов `email_accounts_list` и `list_teams`. Отчитайся
четырьмя строками: скрипт, правила, почта, Linear. Расширенную диагностику —
только если попросят.

## Регистрация команды в Telegram

Если `/jarvis` не срабатывает и приходит «Unknown command»:

- Команда должна быть зарегистрирована в гейтвее **без обязательных
  аргументов**. Варианты режимов передаются текстом после команды или через
  меню — см. SKILL.md.
- Имя команды по требованиям Telegram: 1–32 символа, только `a-z0-9_`.
  `/jarvis_setup` допустимо, `/jarvis-setup` — нет.
- Меню команд в гейтвее ограничено по количеству; при большом числе скиллов
  команда может просто не попасть в список. Проверь фактический список,
  зарегистрированный ботом, прежде чем искать проблему в скилле.
