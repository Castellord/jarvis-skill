Рабочие правила скилла.

- `routing-rules.yaml` — правила шума, категории роутинга и дефолтные Linear
  team/project. Создаётся автоматически: `python3 scripts/jarvis.py init`.
  Пополняется фидбеком пользователя, см. `references/feedback.md`.

`state.yaml` больше нет и не будет. Рантайм-состояние (что уже разобрано, что
важное, по чему заведена задача) хранится метками в самом почтовом ящике —
каталог скилла может быть перезаписан при редеплое, почта нет. Подробности в
разделе SKILL.md «Состояние живёт в почте».
